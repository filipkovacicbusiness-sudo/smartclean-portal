POMEMBNO: GitHub zip datoteke NE razpakira sam. Najprej razpakiraj to
mapo na Macu, nato v brskalnik povleci VSEBINO (ne zip datoteke).

───────────────────────────────────────────────────────────────────
1. NALOŽI  —  repozitorij → Add file → Upload files
───────────────────────────────────────────────────────────────────
Povleci teh 5 datotek in mapo baza/ (skupaj s podmapama tablica in
mobile — GitHub ohrani strukturo, če povlečeš cele mape):

    index.html
    portal.js
    sw.js
    tablica/index.html
    mobile/index.html
    baza/                  (nova mapa: README.md + 3 SQL datoteke)

───────────────────────────────────────────────────────────────────
2. IZBRIŠI na GitHubu  —  odpri datoteko → koš (Delete file)
───────────────────────────────────────────────────────────────────
Tega zip ne more narediti namesto tebe:

    Pralnica-sync.apk            ← napačno poimenovan JSON, ne APK
                                   (pravi APK je v tablica/ in ostane)
    download                     ← tavajoča slika brez končnice
    _fd.html                     ← razvojni ostanek

    45_skrij_neuporabljene.sql   ← preseljeno v baza/
    cenik_pocisti_nepovezane.sql ← preseljeno v baza/
    id_kljuc_migracija.sql       ← preseljeno v baza/

───────────────────────────────────────────────────────────────────
3. PO OBJAVI
───────────────────────────────────────────────────────────────────
Ko se GitHub Pages osveži, v portalu odpri
    Konzola → »Osveži aplikacijo vsem«
da vsi prijavljeni takoj dobijo novo različico.
